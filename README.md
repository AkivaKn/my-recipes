# My Recipes

## Project Description

MyRecipes is a recipe sharing web application that allows users to create, organise, and manage their favorite recipes. Users can input detailed recipes with ingredients and instructions, share them, and explore recipes added by others. The app includes a custom unit system, allowing users to select ingredient units for clear and accurate recipe entries. Users can also edit recipes, add new ingredients, and categorise them, making it a flexible solution for both casual and advanced cooks.

### Key Features:
- Add and organise recipes with ingredients and step-by-step instructions
- Specify ingredient quantities with custom units, enabling flexible measurements
- Edit, delete, or add new ingredients dynamically
- Categorise recipes and manage instructions in a streamlined format

### Technologies Used
- ASP.NET for backend logic and routing
- jQuery and AJAX for dynamic updates and interactive elements
- Bootstrap for responsive design
- Azure for hosting and database management
